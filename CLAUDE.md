# Rescue Grid

Flood SOS coordination: multilingual intake, geocoding, de-duplication, explainable triage, OR-Tools dispatch with coordinator approval, a field PWA and a public tracker. Good here means a coordinator can trust every pin, score and proposal at 3 a.m., and a family on a weak signal can ask for help in their own language. The six specs in `docs/` are the source of truth.

## Commands
- `just dev`: API on :8000 (workers inline) and web on :3100; `just setup` first on a fresh clone
- `just check`: ruff, basedpyright, pytest, Biome, tsc, bun test (must pass before any commit)
- `just fmt`: fix formatting and autofixable lint
- `just e2e`: Playwright journeys plus axe against a running stack (`BASE_URL=http://localhost` for `just stack`)
- `just eval` / `just bench`: quality and FCFS comparison; both write the numbers the landing page quotes
- `just types`: regenerate `apps/web/lib/api-types.ts` after any API schema change

## Layout
- `apps/api/app`: `routers` (HTTP), `actions` (use cases with a session), `services` (pure logic: geocode, dedup, triage, dispatch), `agents` (message reading), `llm` (one `generate()` per provider), `workers` (Redis stream loops)
- `apps/api/alembic/versions`: every model change gets an autogenerated migration; run `just migrate` (dev and test DBs)
- `apps/web/app`: `command` (coordinators), `field` (crews, light theme, offline outbox), `sos` (public), `admin`
- `apps/web/e2e`: journeys from `docs/03-App-Flow.md`; `data/`: gazetteer and replay, regenerated by scripts, never hand-edited

## Conventions
- Tests hit real Postgres+PostGIS and Redis (db 1); never mock the database.
- Every user-facing string in the field app and SOS flow exists in all five languages in `lib/i18n.ts`; the i18n test checks placeholders.
- Viewers must never receive phones or diagnoses: mask on the server (`serialize.py`, `ws.py`), not in the UI.
- Text colours use tokens that clear AA; check new pairs, axe runs in e2e.
- Production builds bake `PUBLIC_BASE_URL`, `CONTACT_EMAIL` and `NEXT_PUBLIC_*` at build time; pass them as Docker build args.
- On Windows, write files with Edit/Write or `write_bytes`; Python `write_text` turns LF into CRLF.
